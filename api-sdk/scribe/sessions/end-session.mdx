---
title: "End Session"
openapi: "POST /voice/v1/sessions/{session_id}/end"
---

Lock the session and start processing — no body required. After this call no more audio is accepted.

On `202 Accepted`, poll [Get Session](/api-sdk/scribe/sessions/get-session) (or use a [webhook](/api-sdk/webhooks/getting-started)) until the results are ready.
