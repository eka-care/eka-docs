<Note>
**Results and panels.** Panel search can only be on while result search is on for the same knowledge base. A request that breaks this is refused with a `400` and nothing changes:

| Request | Message | Error code |
|---|---|---|
| Turn `lab_panel` on while `lab_result` is off | `Turn on search for results first` | `turn_on_results_first` |
| Turn `lab_panel` on while `lab_result` is on in a different knowledge base | `Turn on search for results in the same knowledge base first` | `results_in_other_kb` |
| Turn `lab_result` off while `lab_panel` is on in the same knowledge base | `Turn off search for panels first` | `turn_off_panels_first` |

Turn results on before panels, and panels off before results.
</Note>
