This recipe turns whatever arrives at a clinic, a spoken consultation, a photo of a lab report or a PDF, into one structured medical record. It uses [Scribe](/docs/scribe/overview), [Document Parsing](/docs/models/medical-document-parsing) and [Health Records](/docs/health-records/upload-records).

<Steps>
  <Step title="Turn the consultation into a note">
    Record or stream the consultation with [Scribe](/docs/scribe/quickstart). It returns a structured note in the [template](/api-sdk/scribe/templates/list-templates) you choose, and a [FHIR bundle](/docs/scribe/resources/fhir-structure).
  </Step>
  <Step title="Read reports, PDFs and photos">
    Upload a lab report as a PDF or an image with [Document Parsing](/docs/models/medical-document-parsing). It returns the values in the report as structured data.
  </Step>
  <Step title="Code what was found">
    Map the diagnoses, medicines and tests to standard codes with [medical entity codification](/docs/models/medical-entity-codification), so other systems can read them.
  </Step>
  <Step title="Keep it in the patient's record">
    Save the note and the parsed report against the patient with [Health Records](/docs/health-records/upload-records).
  </Step>
</Steps>

To have a coding agent build this with you, see Build with AI for [Scribe](/docs/scribe/build-with-ai) and [Document Parsing](/docs/models/build-with-ai).
