This recipe adds clinical AI to a hospital system: notes that write themselves, an assistant doctors can ask, and agents that act on the EMR. It uses [Scribe](/docs/scribe/overview), [Agents](/docs/agents/medassist) and [Medical Knowledge](/docs/datasets/overview).

<Steps>
  <Step title="Write the note while the doctor talks">
    Add [Scribe](/docs/scribe/quickstart) to the consultation screen, so each visit ends with a structured note in your template.
  </Step>
  <Step title="Give doctors an assistant">
    Embed [MedAssist](/docs/agents/medassist) for medical questions during the visit.
  </Step>
  <Step title="Ground answers in Indian medical knowledge">
    Look up drugs, labs and treatment protocols with [Medical Knowledge](/docs/datasets/overview), or give an assistant the same data through the [MedAI Tools MCP server](/docs/datasets/build-with-ai/mcp-server/introduction).
  </Step>
  <Step title="Let agents act on the EMR">
    Build an agent for one job with the [Echo Agent Kit](/docs/agents/agent-kit/introduction). Give it patients, appointments and prescriptions through the [EMR MCP server](/docs/emr/build-with-ai/mcp-server/introduction).
  </Step>
</Steps>

To have a coding agent build this with you, see Build with AI for [Agents](/docs/agents/build-with-ai) and [Scribe](/docs/scribe/build-with-ai).
