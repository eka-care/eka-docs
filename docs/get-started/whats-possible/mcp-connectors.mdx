Eka publishes its data and actions as MCP servers. An MCP server is a connector. Once your agent connects to one, the server's tools appear in the agent, and it calls them when a question needs them. Any MCP client works, from Claude and Cursor to an agent you build yourself.

## The servers

| Server | What your agent can do with it | Address | Sign-in |
| --- | --- | --- | --- |
| [Eka EMR MCP](/docs/emr/build-with-ai/mcp-server/introduction) | Search and register patients, book and manage appointments, create prescriptions, read doctor and clinic data | `https://mcp.eka.care/mcp` | Your Eka.care account, on first connect. A self-hosted version uses a client ID and secret instead |
| [MedAI Tools MCP](/docs/datasets/build-with-ai/mcp-server/introduction) | Search Indian branded drugs, find treatment protocols, look up pharmacology, run clinical calculators | `https://medai-tools.eka.care/mcp` | Your Eka account, on first connect |

<Steps>
  <Step title="Pick the servers your agent needs">
    An agent that acts on a clinic's records needs the Eka EMR server. An agent that answers clinical questions needs MedAI Tools. An agent can use both at once.
  </Step>
  <Step title="Connect an assistant you already use">
    In Claude, Cursor or VS Code, add the server's address as a remote MCP server and sign in when asked. Each server's page has the steps for every client: [Eka EMR](/docs/emr/build-with-ai/mcp-server/remote-mcp) and [MedAI Tools](/docs/datasets/build-with-ai/mcp-server/quickstart).
  </Step>
  <Step title="Or connect your own agent">
    With the [Echo Agent Kit](/docs/agents/agent-kit/introduction), point an MCP connection at the server's address and pass its tools to your agent. The [MCP integration](/docs/agents/agent-kit/mcp-integration) page shows the code, including how to connect several servers at once.
  </Step>
  <Step title="Check what the agent can call">
    List the tools the server gives your agent before you rely on them. The full lists are on the [Eka EMR tools](/docs/emr/build-with-ai/mcp-server/supported-tools) and [MedAI Tools tools](/docs/datasets/build-with-ai/mcp-server/tools) pages.
  </Step>
</Steps>

To have a coding assistant build an agent like this with you, see [Build with AI for Medical Agents](/docs/agents/build-with-ai).
