## Install the skill

The `eka-emr` skill carries the hosts, auth and headers, and every Eka EMR operation, each with a link to its page here. It is built from these docs, so it changes when they do.

In Claude Code:

```bash
/plugin marketplace add eka-care/eka-docs
/plugin install eka-emr@eka-docs
```

In Cursor, Codex or another agent, copy the [skill folder](https://github.com/eka-care/eka-docs/tree/main/plugins/eka-emr/skills/eka-emr) into the folder your agent loads skills from. Its map is [`SKILL.md`](https://raw.githubusercontent.com/eka-care/eka-docs/main/plugins/eka-emr/skills/eka-emr/SKILL.md).

## Connect the MCP server

The Eka MCP server is hosted at `https://mcp.eka.care/mcp`. You sign in with your Eka.care account the first time your assistant connects.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add eka-care --transport http https://mcp.eka.care/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    ```json mcp.json
    {
      "mcpServers": {
        "eka-care": {
          "url": "https://mcp.eka.care/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    ```json settings.json
    {
      "mcp": {
        "servers": {
          "eka-care": {
            "type": "http",
            "url": "https://mcp.eka.care/mcp"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

Setup for every other client, sign-in and the full tool list are on the [Eka MCP server](/docs/emr/build-with-ai/mcp-server/introduction) pages.
