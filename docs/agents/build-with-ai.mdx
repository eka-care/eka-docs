## Install the skill

The `eka-agents` skill carries the hosts, auth and headers, and every Agents operation, each with a link to its page here. It is built from these docs, so it changes when they do.

In Claude Code:

```bash
/plugin marketplace add eka-care/eka-docs
/plugin install eka-agents@eka-docs
```

In Cursor, Codex or another agent, copy the [skill folder](https://github.com/eka-care/eka-docs/tree/main/plugins/eka-agents/skills/eka-agents) into the folder your agent loads skills from. Its map is [`SKILL.md`](https://raw.githubusercontent.com/eka-care/eka-docs/main/plugins/eka-agents/skills/eka-agents/SKILL.md).

## Give your agent Eka's tools

An agent built with the [Echo Agent Kit](/docs/agents/agent-kit/introduction) connects to MCP servers as its tools. Two Eka servers are ready to use: the [EMR MCP server](/docs/emr/build-with-ai/mcp-server/introduction) and the [MedAI Tools MCP server](/docs/datasets/build-with-ai/mcp-server/introduction). The [MCP integration](/docs/agents/agent-kit/mcp-integration) page shows how to connect one.
