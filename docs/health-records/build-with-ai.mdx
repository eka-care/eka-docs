## Install the skill

The `eka-health-records` skill carries the hosts, auth and headers, and every Health Records operation, each with a link to its page here. It is built from these docs, so it changes when they do.

In Claude Code:

```bash
/plugin marketplace add eka-care/eka-docs
/plugin install eka-health-records@eka-docs
```

In Cursor, Codex or another agent, copy the [skill folder](https://github.com/eka-care/eka-docs/tree/main/plugins/eka-health-records/skills/eka-health-records) into the folder your agent loads skills from. Its map is [`SKILL.md`](https://raw.githubusercontent.com/eka-care/eka-docs/main/plugins/eka-health-records/skills/eka-health-records/SKILL.md).
