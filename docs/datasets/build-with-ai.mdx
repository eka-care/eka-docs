## Install the skill

The `eka-medical-knowledge` skill carries the hosts, auth and headers, and every Medical Knowledge operation, each with a link to its page here. It is built from these docs, so it changes when they do.

In Claude Code:

```bash
/plugin marketplace add eka-care/eka-docs
/plugin install eka-medical-knowledge@eka-docs
```

In Cursor, Codex or another agent, copy the [skill folder](https://github.com/eka-care/eka-docs/tree/main/plugins/eka-medical-knowledge/skills/eka-medical-knowledge) into the folder your agent loads skills from. Its map is [`SKILL.md`](https://raw.githubusercontent.com/eka-care/eka-docs/main/plugins/eka-medical-knowledge/skills/eka-medical-knowledge/SKILL.md).

## Connect the MCP server

The MedAI Tools MCP server is hosted at `https://medai-tools.eka.care/mcp`. You sign in with your Eka.care account the first time your assistant connects.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add medai-tools --transport http https://medai-tools.eka.care/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    ```json mcp.json
    {
      "mcpServers": {
        "medai-tools": {
          "url": "https://medai-tools.eka.care/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    ```json settings.json
    {
      "mcp": {
        "servers": {
          "medai-tools": {
            "type": "http",
            "url": "https://medai-tools.eka.care/mcp"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

Setup for every other client, sign-in and the full tool list are on the [MedAI Tools MCP server](/docs/datasets/build-with-ai/mcp-server/introduction) pages.
