Eka publishes the code it builds for Indian healthcare under open licences. Each card opens the project's GitHub repository, where you find its README, its releases and its issue tracker. Every project here is MIT licensed unless its card says otherwise.

For Eka's open models and datasets as well as its code, see the [full open source catalogue](https://eka-care.github.io/open-source/).

## Agents and medical AI

<CardGroup cols={2}>
  <Card title="Echo SDK" icon="robot" href="https://github.com/eka-care/echo-sdk">
    One agent SDK for Bedrock, OpenAI and Anthropic, alone or inside CrewAI and LangGraph.

    `pip install git+https://github.com/eka-care/echo-sdk.git`
  </Card>
  <Card title="Eka MCP Server" icon="plug" href="https://github.com/eka-care/eka_mcp_server">
    Ground an LLM in Indian drug and treatment-protocol data over MCP.

    `uvx eka_mcp_server`
  </Card>
  <Card title="KARMA OpenMedEvalKit" icon="flask" href="https://github.com/eka-care/KARMA-OpenMedEvalKit">
    Evaluate medical AI models on text, image and audio in one framework.

    `pip install karma-medeval`
  </Card>
  <Card title="document-pii-redactor" icon="user-shield" href="https://github.com/eka-care/document-pii-redactor">
    Find and redact personal data in document images and text. Built for Indian documents, and runs on a CPU. Apache-2.0 licensed.

    `pip install document-pii-redactor`
  </Card>
</CardGroup>

## Documents and printing

<CardGroup cols={2}>
  <Card title="Patra" icon="file-lines" href="https://github.com/eka-care/patra">
    Design a printable document, then render it with data.

    `npm install github:eka-care/patra#patra-engine-v0.1.0`
  </Card>
  <Card title="Pagify SDK" icon="file-pdf" href="https://github.com/eka-care/Pagify-sdk">
    Render HTML as paginated, print-ready PDFs in the browser, with headers and page numbers.

    `npm install @eka-care/pagify-sdk`
  </Card>
  <Card title="Paged.js (Eka fork)" icon="code-fork" href="https://github.com/eka-care/pagedjs/tree/eka/v0.4">
    Table pagination fixes for Paged.js 0.4.3, used to print prescriptions and bills.

    `git clone -b eka/v0.4 https://github.com/eka-care/pagedjs`
  </Card>
</CardGroup>

## App building blocks

<CardGroup cols={2}>
  <Card title="Aangan" icon="table-cells-large" href="https://github.com/eka-care/aangan">
    Compose a home screen from independent providers, ranked and capped per zone.

    `npm install github:eka-care/aangan#aangan-contract-v0.1.0`
  </Card>
  <Card title="Awaaz" icon="comments" href="https://github.com/eka-care/awaaz">
    Collect product feedback, such as ideas, bugs and votes, and move it through a status lifecycle.

    `npm install github:eka-care/awaaz#awaaz-contract-v0.1.0`
  </Card>
  <Card title="POS Terminal Mock" icon="credit-card" href="https://github.com/eka-care/pos-terminal-mock">
    A stand-in card machine, so you can build a POS integration without the hardware.

    `npx github:eka-care/pos-terminal-mock`
  </Card>
</CardGroup>

## Contribute

Each project takes issues and pull requests on its own repository. To report a bug or propose a fix, open an issue on that project's GitHub page. Every Eka repository is listed on [github.com/eka-care](https://github.com/eka-care).
