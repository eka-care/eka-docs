An Eka agent is one you build and configure for a job: answer a patient's questions, take a clinic's bookings, or look up a drug for a doctor. You choose the model, the tools and the instructions. MedAssist is one ready-made agent you can embed as it is.

## What you build with

<CardGroup cols={2}>
  <Card title="Echo Agent Kit" icon="robot" href="/docs/agents/agent-kit/introduction">
    An open-source Python framework for agents. It works with OpenAI, Anthropic or Gemini, and calls your tools and MCP servers.
  </Card>
  <Card title="EMR MCP server" icon="plug" href="/docs/emr/build-with-ai/mcp-server/introduction">
    Lets an agent book appointments, manage patients and create prescriptions in Eka's EMR.
  </Card>
  <Card title="MedAI Tools MCP server" icon="stethoscope" href="/docs/datasets/build-with-ai/mcp-server/introduction">
    Gives an agent drug search, treatment protocols, pharmacology and clinical calculators.
  </Card>
  <Card title="MedAssist" icon="comments" href="/docs/agents/medassist">
    Eka's ready-made medical assistant. It holds real-time conversations on Eka's medical model.
  </Card>
  <Card title="Synapse client SDK" icon="message" href="/docs/agents/synapse/introduction">
    Puts an agent in a website, a React app or your own interface, over a real-time session.
  </Card>
</CardGroup>

## How they fit together

<Steps>
  <Step title="Build the agent">
    Write the agent with the [Echo Agent Kit quickstart](/docs/agents/agent-kit/quickstart): pick the model, set its instructions and add tools.
  </Step>
  <Step title="Give it Eka's tools">
    Connect the [EMR MCP server](/docs/emr/build-with-ai/mcp-server/introduction) so it can act on patients and appointments. Connect the [MedAI Tools MCP server](/docs/datasets/build-with-ai/mcp-server/introduction) so its answers rest on verified medical data.
  </Step>
  <Step title="Put it in front of users">
    Embed it with the [Synapse client SDK](/docs/agents/synapse/introduction), or use [MedAssist](/docs/agents/medassist) if a ready-made assistant fits.
  </Step>
</Steps>
