# Ask AI Widget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** developer.eka.care gets its own "Ask AI" panel, adapted from the ABDM support agent widget. It's reached from a floating bar on every page and from a row in Mintlify's search box, and it runs in mock mode until a Synapse agent is wired behind it.

**Architecture:** The widget source lives in `ask-ai/`, which Mintlify ignores. It is a copy of `nha-in/ai-widget/src` with the ABDM-specific parts removed and the network layer replaced by a session-shaped `Transport` interface. Its only implementation for now is a mock. esbuild bundles it into one committed file, `ask-ai.js`, at the content root. Mintlify loads that file on every page, and it registers `<eka-ask-ai>`, mounts one instance, and adds the "Ask AI" row to the search box.

**Tech Stack:** Preact 10 (with `preact/compat` aliased for `@paper-design/shaders-react`), TypeScript, esbuild, Node `assert` tests, and Mintlify custom JS.

**Spec:** `docs/superpowers/specs/2026-10-14-ask-ai-widget-design.md`

## Global Constraints

- Branch `feat/ask-ai-widget` in its own worktree, based on `feat/eka-docs-contributor`. Never touch the main checkout's uncommitted `docs.json`, `styles.css` or `scripts/build-nav.py` changes.
- Source: `/Users/samdennis/code/nha-in/ai-widget` (MIT, Copyright (c) 2026 National Health Authority (NHA)). Copy it; never modify it. Keep the NHA notice in `ask-ai/LICENSE`.
- The element name is `<eka-ask-ai>`. Storage keys use the prefix `eka-ask-ai-`, not `abdm-ask-ai-`.
- Add `ask-ai/` to `.mintignore`. The only new file Mintlify sees is `ask-ai.js`.
- `ask-ai.js` starts with `// Generated by ask-ai/build.mjs. Do not edit.` It is committed, and it stays under 200KB.
- No `vendor/` folder. pdf.js, Tesseract and mermaid are not copied, loaded or referenced.
- The accent colour comes from `docs.json` `colors.primary` (light ground) and `colors.light` (dark ground), read when the widget is built.
- Mock mode is used whenever no `agent-id` attribute is set. The panel then shows the "Mock" badge, and every mock reply says it is a mock.
- Never place the search row inside Mintlify's `[role=listbox]`.
- Prose rules from `writing-style`: no em dashes in any user-visible string.

## Review Focus

1. **Mintlify's client-side navigation re-renders the page.** The `<eka-ask-ai>` element and the floating bar must still be there after moving between pages, with the open conversation intact. Owned by Task 5; tested in Task 7.
2. **The search dialog opens, closes and re-renders many times.** There must never be more than one Ask AI row. Owned by Task 6 (`ensureRow` is idempotent); checked in the browser in Task 7 (reopen three times).
3. **An empty or whitespace-only search query.** No row should show. Owned by Task 6.
4. **`localStorage` or `sessionStorage` blocked**, as in Safari private mode. The panel must still open and answer. The source's try/catch is kept. Owned by Task 4, which tests `load` with storage that throws.
5. **The script evaluated twice.** There must be exactly one element and one listener set. Owned by Task 5, with a guard on `customElements.get` and an existing `eka-ask-ai` element.

- Produces, in `transport.ts`:

```ts
export type SessionRef = {sessionId: string; sessionToken: string};
export type TransportHandlers = {
  onText: (delta: string) => void;
  onProgress: (text: string) => void;
  onTips: (tips: string[]) => void;
  onDone: () => void;
  onError: (message: string) => void;
};
export type OutgoingMessage = {text: string; files: File[]; page?: PageAttachment};
export interface Transport {
  readonly isMock: boolean;
  start(existing?: SessionRef): Promise<SessionRef>;
  send(message: OutgoingMessage, handlers: TransportHandlers): void;
  /** Stops delivering the current reply. The backend may keep generating it. */
  detach(): void;
  end(): Promise<void>;
}
export function createTransport(config: {agentId?: string; authToken?: string}): Transport;
export const UNREACHABLE: string; // moved from sse.ts, same text
```

  `createTransport` returns `mockTransport()` when `agentId` is empty, and otherwise throws `Error('Synapse transport not wired yet')`. That throw is the single place the Synapse team replaces.
- Produces, in `history.ts`: `Session` gains `session?: SessionRef`. `Turn.file` keeps `Attached`. The raw `File` is held only in memory, never saved.
- `Source` moves to `types.ts`.
