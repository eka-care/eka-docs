# Developer tools and copy prompts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put a Developer tools pill group in the landing hero and in both navs, back it with a generated `/developer-tools` page, and replace the landing's illustrative code panel with tested copy prompts.

**Architecture:** `scripts/build-nav.py` already generates `api-sdk/index.mdx` from `docs.json`. It gains a second writer for `developer-tools.mdx`, and it owns the Mintlify navbar link. The landing changes go in `landing/source.html` and are rebuilt into `snippets/landing.jsx` by `scripts/build-landing.mjs`. The prompt is a pure function in the page script, tested through `vm` the way `landing.test.mjs` already tests `J` and `GROUPS`.

**Tech Stack:** Mintlify (`mint@4.2.1018` dev on port 3334), Python 3 (`unittest`), Node `node:test`, Lucide icons on the landing page.

**Spec:** `docs/superpowers/specs/2026-10-22-developer-tools-and-copy-prompts-design.md`

## Global Constraints

- Tools, in this order and with these labels: `API reference`, `SDKs`, `MCP servers`, `Webhooks`. The hero pills say `MCP server` (singular, as in the approved mockup). The page section says `MCP servers`.
- Anchors on `/developer-tools`: `#api-reference`, `#sdks`, `#mcp-servers`, `#webhooks`.
- Lucide icons: `braces`, `package`, `plug`, `webhook`.
- No "View more". No agent logos. No new visual component: the pill group reuses `.navlinks` and `.nvb` looks.
- Nothing links to `/mcp/introduction`.
- Generated files carry `{/* Generated by scripts/build-nav.py from docs.json. Do not edit by hand. */}`.
- Prose follows the eka-docs-contributor writing-style skill: second person, no em dashes, no marketing.
- Baseline before any change: `python3 -m unittest discover -s scripts -p 'test_build_nav.py'` gives 18 OK, and `npm test` gives 37 pass. Both must stay green after every task.

## Review Focus

1. A product with no SDK, MCP or webhook pages must not get an empty card. Its section simply omits it, and a section with no products is not written at all. The test lives in Task 1.
2. Running `build-nav.py` twice must give the same `docs.json` and `developer-tools.mdx`. The existing `test_idempotent` covers `docs.json`. Task 1 adds the same check for the page.
3. A scene where the developer has clipped in nothing yet: the panel shows the scene's prompt with no parts, and Copy still works. The test lives in Task 3.
4. A part whose product has no Build with AI page on disk: the prompt leaves that line out rather than linking a 404. The test lives in Task 3.
5. On a 390px screen the pill group never scrolls sideways, and the label wraps to its own row. Task 2 has a manual check. A unit test can't measure layout.

```python
class DevTools(unittest.TestCase):
    def setUp(self):
        self.page = open(os.path.join(ROOT, 'developer-tools.mdx')).read()

    def test_sections_in_order(self):
        heads = [l[3:] for l in self.page.splitlines() if l.startswith('## ')]
        self.assertEqual(heads, ['API reference', 'SDKs', 'MCP servers', 'Webhooks'])

    def test_known_tools_are_listed(self):
        self.assertIn('href="/docs/emr/build-with-ai/mcp-server/introduction"', self.page)
        self.assertIn('href="/docs/datasets/build-with-ai/mcp-server/introduction"', self.page)
        self.assertNotIn('/mcp/introduction"', self.page)

    def test_every_card_points_at_a_page_on_disk(self):
        for href in re.findall(r'href="/([^"#]+)"', self.page):
            self.assertTrue(nav.open_ok(href), href)

    def test_no_product_twice_in_a_section(self):
        for section in self.page.split('\n## ')[1:]:
            titles = re.findall(r'title="([^"]+)"', section)
            self.assertEqual(len(titles), len(set(titles)), section.splitlines()[0])

    def test_navbar_link(self):
        links = json.load(open(os.path.join(ROOT, 'docs.json')))['navbar']['links']
        self.assertEqual(links[0], {'label': 'Developer tools', 'href': '/developer-tools'})

    def test_page_is_stable(self):
        before = self.page
        subprocess.run([sys.executable, 'scripts/build-nav.py'], cwd=ROOT, check=True, capture_output=True)
        self.assertEqual(open(os.path.join(ROOT, 'developer-tools.mdx')).read(), before)
```

const SCENES_SRC = grab(/const SCENES=\{[\s\S]*?\n\};\n/, 'SCENES');
