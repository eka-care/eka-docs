## Install the skill

The `eka-ipd` skill carries the hosts, auth and headers, and every IPD operation, each with a link to its page here. It is built from these docs, so it changes when they do.

In Claude Code:

```bash
/plugin marketplace add eka-care/eka-docs
/plugin install eka-ipd@eka-docs
```

In Cursor, Codex or another agent, copy the [skill folder](https://github.com/eka-care/eka-docs/tree/main/plugins/eka-ipd/skills/eka-ipd) into the folder your agent loads skills from. Its map is [`SKILL.md`](https://raw.githubusercontent.com/eka-care/eka-docs/main/plugins/eka-ipd/skills/eka-ipd/SKILL.md).
