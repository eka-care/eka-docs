## Before you start

Three things have to be in place before anything on this page works.

| What you need | Why |
| --- | --- |
| A coding assistant | Claude Code, Cursor, Codex or ChatGPT. Any one is enough. Pick one and stay on it. |
| A paid plan on it | Free tiers stop partway through a long task. |
| Your own project open in it | The assistant reads and writes the folder it is opened in. Open the repository you are building in first. |

Then work down this page in order: install the skill, connect the MCP server where there is one, and ask for one flow at a time in plain language. Read what the assistant writes before you run it.
