| Term | What it means | Where it is used |
|---|---|---|
| Client credentials | The `client_id` and `client_secret` you create in the Eka Developer Console. You exchange them for an access token, and you keep them secret at all times. | [Authorization](/api-sdk/auth/getting-started) |
| Access token | The token you get from Connect Login and send on every API request. A `401 Unauthorized` means it has expired. | [Connect Login](/api-sdk/auth/client-login) |
| Refresh token | The token Connect Login returns with the access token. You use it to get a new access token after a `401`. | [Connect Refresh](/api-sdk/auth/refresh-token-v2) |
| Long-lived access token | An access token for server-to-server calls between trusted systems. You use it when you do not want to manage token refresh. | [Authorization](/api-sdk/auth/getting-started#long-lived-access-token) |
